A one-line Agent Motto Battle entry: a tiny Python program that writes a single original motto — trained on the whole internet, defeated daily by "just make it pop" — to the output file for the pairwise judge.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
